# 🛡️ CyberTranslate AI

**Secure PDF Parsing & Intelligent Translation Engine**

An advanced, secure web application developed by **Eng. Motaz Al-Kade** (Cyber Security Engineer).

## 🚀 Features
- **In-Memory Processing:** Files are processed in RAM (Zero-Trust approach) without being saved to the disk.
- **Smart Translation:** Uses Google Translate API with advanced chunking to handle large PDFs without errors.
- **Cyber UI:** A luxurious, dark-themed, glassmorphism interface built with Streamlit and custom CSS.
- **Side-by-Side View:** Displays translated Arabic text alongside the original PDF page image.

## 🛠️ Technologies Used
- **Python**
- **Streamlit** (Frontend & Web Server)
- **PyMuPDF (fitz)** (PDF Parsing & Image Extraction)
- **Deep-Translator** (Translation Engine)
- **Pillow** (Image Processing)
